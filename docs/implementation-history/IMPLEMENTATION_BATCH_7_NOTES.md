# Catatan implementasi Batch 7

Ringkasan fitur yang diperkenalkan pada Batch 7 (disusun ulang dari kode karena arsip asli tidak ikut terkirim).

- Peternakan (`js/ranch.js`): kandang berlevel, hewan, pakan 24 jam bergulir, produksi offline terbatas.
- Kehidupan desa (`js/life.js`): memancing, mengumpulkan material, dapur dan buff, tingkat desa, pesanan desa, cuaca dan salju.
- Penyimpanan: batas tas terpusat, hadiah tertunda yang dibatasi, tanpa kehilangan produk secara diam-diam.
- Tes: `tools/test_stage2_batch.js`, `tools/test_life_logic.js`, `tools/test_7defg.py`.

Perubahan setelahnya dicatat di `STAGE-8X-NOTES.md` dan `STAGE-8H-8I-NOTES.md`.
